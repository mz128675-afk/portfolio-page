# Personal Portfolio Page

My first portfolio project — a clean, responsive personal page built with the
web fundamentals I'm learning in my BSCS degree.

## Features
- Responsive navbar and layout (Bootstrap 5)
- Hero section with a greeting that changes by time of day (JavaScript conditionals)
- Skills section, projects section, and contact section
- Footer year that updates itself (JavaScript function)

## Tech used
- HTML5
- CSS3 + Bootstrap 5
- JavaScript (var / let / const, conditionals, functions)

## How to run
Just open `index.html` in any browser. No build step needed.
For a live demo, this page can be hosted free on GitHub Pages.
